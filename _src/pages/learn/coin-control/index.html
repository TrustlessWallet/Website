What the balance contains

Bitcoin records spendable amounts as unspent transaction outputs, commonly called UTXOs. If you receive 30,000 sats and later 20,000 sats, your wallet might show 50,000 sats across two outputs. Tap the on-chain balance to inspect the underlying outputs.

Select inputs and review change

Suppose you spend 10,000 sats. One 20,000-sat output may cover the payment and its fee. The unused portion returns to a change address controlled by your wallet. The exact change depends on the network fee.

  1. Start an on-chain send and open coin control.
  2. Choose outputs whose combined value covers the amount and fee. Combining outputs publicly links them as inputs to the same transaction.
  3. Review the recipient, amount, fee and change before signing. Trustless supports fresh receive and change addresses. Address rotation helps limit direct reuse, while your choice of inputs still matters.

Spend from a watch-only wallet

A partially signed Bitcoin transaction (PSBT) carries the information a signer needs to authorize a payment. Prepare the transaction in the watch-only wallet, transfer the PSBT to your compatible signer, and verify the destination and amount on the signer. Import the signed result back into Trustless to broadcast it.

An extended public key can reveal wallet activity. Share it only with tools or people you trust with that information. Using your own Electrum server gives you control over which server receives those wallet queries.

Common questions

Does choosing fewer inputs always lower my fee?

Each input adds transaction data. At the same fee rate and for similar input types, fewer inputs usually reduce the fee. The output types and number of outputs also affect the final size.

Is coin control used for a Lightning payment?

Coin control selects on-chain outputs. Paying a Lightning invoice uses the Lightning balance.
