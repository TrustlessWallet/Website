Proteggi le chiavi del wallet

La frase di recupero permette di ricostruire le chiavi con cui firmi le transazioni. Seleziona Backup wallet nelle opzioni del wallet, trascrivi le parole nell’ordine esatto e completa la verifica. Conserva la frase in un luogo privato, separato dal telefono. Non inserirla in un sito web e non inviarla all’assistenza.

Se usi Terminal, crea anche un backup cifrato dei dati del negozio. La frase di recupero da sola non ricostruisce lo storico locale delle vendite, i prezzi originali, il catalogo o le impostazioni delle ricevute.

Salva i dati del negozio

  1. Come titolare, seleziona il wallet dell’attività e apri Terminal Settings → Backup → Create.
  2. Scegli e conferma una password di almeno 12 caratteri. Conservala separatamente dal file, in un posto a cui puoi accedere. Trustless non può recuperarla.
  3. Crea il backup. Dal menu di condivisione, salva il file cifrato in un luogo accessibile anche se perdi il telefono. Aggiorna il backup dopo nuove vendite, rimborsi o modifiche al catalogo.

Il CSV delle vendite serve per la contabilità. Per il ripristino nell’app occorre il backup cifrato di Terminal.

Cambia dispositivo

  1. Recupera il wallet originale con la sua frase, oppure selezionalo se è già presente. Usa la stessa rete del backup.
  2. Prima di registrare altre vendite o aggiungere articoli, apri Terminal Settings → Backup → Restore, scegli il file e sbloccalo con la sua password.
  3. Controlla l’anteprima e conferma il ripristino. Sul dispositivo di destinazione lo storico e il catalogo devono essere vuoti. Se il backup contiene impostazioni delle ricevute, modelli o report, anche le relative impostazioni devono essere vuote.
  4. Verifica le vendite e gli articoli ripristinati prima di dismettere il vecchio dispositivo. Per le vendite ripristinate i rimborsi sono disabilitati, perché il backup potrebbe precedere un rimborso già effettuato.

Domande frequenti

L’acquisto di Pro ripristina le mie vendite su un altro telefono?

Il ripristino degli acquisti riattiva l’accesso alle funzioni previste dall’abbonamento. Per recuperare il wallet usa la frase di recupero. Per i dati del negozio usa il backup cifrato di Terminal.

E se perdo la password del backup?

Se Terminal conserva ancora i dati sul dispositivo originale, crea un nuovo backup con una nuova password e custodiscila con cura. Per aprire il vecchio file cifrato serve ancora la password originale.
